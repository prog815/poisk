# Poisk - Корпоративный поисковик для локальной сети

**Статус:** В разработке  
**Версия:** 1.0.0 (целевая)  
**Репозиторий:** https://github.com/prog815/poisk

> Автономная система для быстрого поиска файлов в корпоративных сетях

## 📋 О проекте

Poisk — это решение для поиска файлов в изолированных корпоративных сетях. Система состоит из:
- Python-скрипта для генерации индекса
- Единого HTML-файла с интерфейсом поиска

## 🏗️ Структура проекта

```
poisk/
├── README.md                    # Документация
├── create_distribution.py      # Утилита создания дистрибутива
├── generate_search_page.py    # Основной скрипт генерации
├── template.html              # HTML-шаблон
├── styles.css                 # Стили
├── search.js                  # Логика поиска
└── config.ini                 # Конфигурация
```
